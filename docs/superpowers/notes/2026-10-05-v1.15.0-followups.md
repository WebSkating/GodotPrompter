# v1.15.0 Follow-ups — carried into the next release

Recorded 2026-10-06, at the close of v1.15.0 "Editor Beat". These are the open items the release
surfaced but did not fix. Each says what was verified, so the next author does not have to
re-derive it. It continues `2026-07-28-v1.13.0-followups.md`.

## 1. Mentor eval re-baseline pending

The `no-menu-paths` grader changed from a regex to an `llm` grader in all five mentor cases
(`evals/`). **A full run has not been done** (about 50 minutes and about $15; the judge must stay

## 2. Editor references: what was omitted

**Verified:** `skills/godot-mentor/references/editor-recipes.md` has 20 recipes (none dropped) and
`editor-navigation.md` covers main screens, docks, bottom panels, Project Settings tabs and top
menus. Both were checked against the godot-docs branches 4.3 to 4.7 and, where the docs lag the
editor, against the engine source at the tags 4.3-stable to 4.7-stable. The digest is
`docs/superpowers/notes/2026-10-05-godot-editor-research.md` (about 270 claims, about 40 omitted
items). **Nothing was checked in a running editor.**

The digest's `## Omitted` section holds the full list. By category:

- **Literal button and field labels not read** — confirm buttons, the Event Configuration dialog's
  listening field, Layer Names field labels, import-type selector, Theme and Translations dialogs.
- **Layout and ordering** — bottom panel button order, dock tab positions after customisation,
  the 4.7 left/right bottom slots, Scene dock toolbar order and icons.
- **Which node or resource shows a contextual panel** — and whether Shader Editor and Version
  Control are hidden until used on 4.3 to 4.5.
- **Features outside the listed recipes** — TileSet terrain, alternative tiles, navigation and
  occlusion; the Game main screen toolbar; Network Profiler and Monitors strings; keyboard
  shortcuts the docs do not quote.
- **Flows the fetched pages stop short of** — AssetLib install after Download, per-platform
  export options, assigning an existing theme file, multi-select groups across versions.

Open items:

- **(a) Three 4.7 claims contradict the 4.7 docs** and rest on engine source, confirmed by two
  independent readers but not in a running 4.7 editor: the main-screen button reads "Asset Store";
  the Autoload tab has Select Script/Scene, Create Script, Create Scene instead of Path / Node
  Name / Add; the Create New Group confirm button reads "Create".
- **(b) Seven recipes stop at the last step the sources support** and say what remains: custom
  Resource, Input Map (Event Configuration dialog), physics layers, translation file, addon
  install, export preset, main scene.
- **(c) In `editor-navigation.md`** the "reopen" cell is "—" for Shader Editor on 4.3 to 4.5,
  Version Control, and MeshLibrary on 4.7, and four panels are marked context-only without the
  trigger.
- **(d) Re-check both references at Godot 4.8.**
- **(e) Version-flag coverage.** The version-flag gap/overlap test covers `editor-recipes.md` only; `editor-navigation.md`'s version ranges are not machine-checked.

## 3. Cursor hook: not run end to end

**Outcome (the v1.15.0 Cursor hook check): unchanged.** `hooks/hooks-cursor.json` was not edited; a test now pins the
command's shape. Cursor's docs (https://cursor.com/docs/hooks.md and
https://cursor.com/docs/reference/plugins.md, read 2026-10-06) do not document, for
plugin-registered hooks:

1. the working directory (it is listed only for project, user, enterprise and team hooks);
2. expansion of a plugin-root variable inside a hook command (documented for the MCP config only);
3. the shell used on Windows;
4. `CURSOR_PLUGIN_ROOT` being exported to hook processes (the hooks environment table lists
   `CURSOR_PROJECT_DIR`, `CURSOR_VERSION`, `CURSOR_USER_EMAIL`, `CURSOR_TRANSCRIPT_PATH`,
   `CURSOR_CODE_REMOTE` and `CLAUDE_PROJECT_DIR`).

**Leading open risk:** `hooks/session-start` chooses Cursor's `additional_context` output shape
only when `CURSOR_PLUGIN_ROOT` is set. If Cursor does not export it, the hook emits
`additionalContext` and the card may be dropped under Cursor. The hook was not changed.

Still needed: one real Cursor session on Windows and one on macOS or Linux.

## 4. Android C#: not device-tested

Three C# blocks in `skills/mobile-development/references/plugins.md` (Android v2 plugins and
`JavaClassWrapper`), each labelled not device-tested. Signatures were checked against the class
reference (4.3, 4.4, 4.7) and the engine's C# bindings generator; nothing was built with Gradle
or run on a device. Caveat: the EditorPlugin/EditorExportPlugin snippet shows two classes
together; in a real project `MyAndroidPlugin` must live in its own same-named `.cs` file.
