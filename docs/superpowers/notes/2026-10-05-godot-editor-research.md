# Godot Editor Research Digest — 4.3 to 4.7

**Researched:** 2026-10-05
**Sources:** godotengine/godot-docs branches 4.3, 4.4, 4.5, 4.6, 4.7 (raw .rst);
godotengine/godot tags 4.3-stable to 4.7-stable where noted.
**Used by:** skills/godot-mentor/references/editor-navigation.md, editor-recipes.md

## Method

All 28 docs pages in the source table were fetched from `raw.githubusercontent.com/godotengine/godot-docs/<branch>/<path>` for each of the five branches (140 files, none missing) and every file was diffed between adjacent branches; every changed diff was read. UI strings below are quoted as the 4.7 docs page writes them, with the first branch where the wording differs noted. Where the docs do not state a label or location, or where a docs page is unchanged across branches while the editor changed, the label was read from the engine's `editor/` directory at the matching `<version>-stable` tag (strings inside `TTR("…")` / `TTRC("…")`), and the row cites the engine file and tags. Anything neither source settles is listed under Omitted rather than filled in.

**Addendum, 2026-10-06:** the rows on reopening docks and opening bottom panels, the dock tab order from the default layout, and the correction to **ResourcePreloader** were added from a second read of `editor/` at all five tags (sparse checkout of each `<version>-stable` tag), after the first pass left "how to reopen a closed dock" unanswered.

Reading the tables:

- **docs** paths are relative to the godot-docs repository; `@ 4.3-4.7` means the wording is present on every branch in that range.
- **engine** paths are relative to godotengine/godot at the `<version>-stable` tag. Many files moved in 4.5; both locations are given as `old path (4.3-4.4) / new path (4.5-4.7)`.
- A row marked **engine wins** records a case where the docs wording and the engine string differ; the engine string is what the editor displays.
- Engine strings ending in `...` are written with three ASCII dots exactly as in the source.

## Version differences

- **Game main screen** — absent in 4.3 (four main screens: 2D, 3D, Script, AssetLib); present from 4.4 (five: 2D, 3D, Script, Game, AssetLib). Docs changed on the 4.4 branch; engine confirms (`game_view_plugin` first exists at 4.4-stable).
- **AssetLib → Asset Store** — the main screen button reads **AssetLib** on 4.3-4.6 and **Asset Store** on 4.7; the Project Manager tab reads **Asset Library** (4.3-4.6 engine, all docs) and **Asset Store** on 4.7. Settled by engine source (`editor/asset_library/asset_library_editor_plugin.h`, `editor/project_manager/project_manager.cpp` @ 4.7-stable; `editor/project_manager.cpp` @ 4.3, 4.4 for the older label); the 4.7 docs still say "AssetLib" / "Asset Library".
- **Node dock → Signals dock + Groups dock** — 4.3-4.5 have one **Node** dock (right side, tab after **Inspector**) with **Signals** and **Groups** buttons inside it; 4.6 and 4.7 have separate **Signals** and **Groups** docks in the same right-side slot. Docs changed on the 4.6 branch; engine confirms (`editor/docks/node_dock.cpp` gone, `signals_dock.cpp` and `groups_dock.cpp` present at 4.6-stable).
- **History dock position** — right side, third tab after Inspector and Node on 4.3-4.5; left side lower slot, next to FileSystem, on 4.6-4.7. Engine source only.
- **Autoload add form** — **Path:** / **Node Name:** fields and an **Add** button on 4.3-4.6; **Select Script/Scene**, **Create Script**, **Create Scene** buttons on 4.7, with the name taken from the file name. Engine source only (`editor/settings/editor_autoload_settings.cpp` @ 4.7-stable); the docs page is byte-identical from 4.6 to 4.7.
- **Autoload tab location** — unchanged: **Project Settings > Globals > Autoload** on every version 4.3-4.7 (docs and engine agree; the Globals tab already exists at 4.3-stable).
- **Project Settings tabs** — a **GDExtension** tab is added between **Plugins** and **Import Defaults** in 4.7. Engine source only.
- **Inspector "New <Type>" entry** — "New SpriteFrames" / "New Theme" style entries on 4.3-4.4; a **New** header followed by bare type names on 4.5-4.7. Engine source only; the docs keep the old wording on every branch.
- **Localization third sub-tab** — **POT Generation** on 4.3-4.5, **Template Generation** on 4.6-4.7. Engine source only.
- **Localization > Translations** — not a UI change: the sub-tab exists on every version; only the docs wording changed on the 4.6 branch.
- **Create New Node dialog** — not a UI change: the title is **Create New Node** on every tag; the docs wrote "Create Node dialog" until the 4.5 branch.
- **Create New Group confirm button** — default confirm button on 4.3-4.6 (docs: "press Ok"); labelled **Create** on 4.7. Engine source only.
- **Debugger first tab** — not a UI change: **Stack Trace** on every tag; the 4.3 docs headed the section "Debugger".
- **Evaluator tab** — added to the Debugger panel in 4.4 (docs and engine).
- **Step Out** — added to the debugger controls in 4.6 (engine source only).
- **Profiler Autostart** — checkbox added in 4.4 (docs and engine).
- **Animation markers** — **Insert Marker...** added in 4.4 (docs and engine).
- **Animation playback tooltips** — "Play selected animation from start. (Shift+D)" on 4.3; **Play Animation from Start** from 4.4. Engine source only.
- **Export preset tabs** — **Patches** tab added in 4.4, renamed **Patching** in 4.6. Engine source only.
- **Export Template Manager** — **Download and Install** / **Install from File** on 4.3-4.6; **Install Selected Templates** (reads **Install All Templates** with no box checked) with per-platform checkboxes on 4.7 (docs changed on the 4.7 branch; engine confirms).
- **SpriteFrames icon-button tooltips** — the icon buttons whose tooltips read **Add frames from sprite sheet** / **Add frame from file** on 4.3-4.5 are title-cased to **Add Frames from Sprite Sheet** / **Add Frame from File** on 4.6-4.7 (shortcut names, not visible captions). Engine source only (`editor/scene/sprite_frames_editor_plugin.cpp` @ 4.6-stable).
- **TileMap tool tooltips** — shortcut names **Paint**, **Rect**, **Bucket** … on 4.3 become **Paint Tool**, **Rect Tool**, **Bucket Tool** … on 4.4-4.7. Engine source only (`editor/plugins/tiles/tiles_editor_plugin.cpp` @ 4.3, 4.4).
- **Bottom panels** — **Polygon** added in 4.4, **MeshLibrary** in 4.7; **ResourcePreloader** is present on every version (an earlier pass of this digest dated it to 4.5 because its name is not a translated string at 4.3-4.4). From 4.6 the bottom panels are registered as docks with a bottom default slot. Engine source only.
- **Opening a bottom panel** — a named toggle button in the bottom bar on 4.3-4.5; a named tab of the bottom panel on 4.6-4.7 (the bottom panel became a tab container holding docks). Engine source only.
- **Editor > Editor Docks contents** — lists every dock at 4.3 (disabled ones greyed out); skips disabled docks and gains "Open the <name> dock." / "Focus on the <name> dock." tooltips from 4.4; from 4.6 lists only `global` docks, which now include the bottom panels **Output**, **Audio**, **Animation**, **Shader Editor** (and **Debugger** on 4.7). - **Dock options popup** — **Move to Bottom** present on 4.3-4.5, absent on 4.6-4.7; on 4.6-4.7 **Close** can be disabled with the tooltip "This dock can't be closed.". Engine source only.

- **Input Map filter** — **Filter by Name** field with **Clear All** on 4.3-4.4; those strings are gone from the file at 4.5. Engine source only.
